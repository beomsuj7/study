# 예시 - 코딩테스트 문제풀이

> 해시를 활용한 코딩테스트 예시 문제 풀이 정리

---

## 문제: 두 수의 합 (Two Sum)

정수 배열 `nums`와 정수 `target`이 주어질 때, 합이 `target`이 되는 두 수의 인덱스를 반환하라.

### 접근 방법

- **해시맵**을 사용하여 O(n) 시간복잡도로 해결
- 배열을 순회하면서 `target - nums[i]` 가 해시맵에 있는지 확인

### 풀이 코드

```python
def two_sum(nums, target):
    hash_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in hash_map:
            return [hash_map[complement], i]
        hash_map[num] = i
    return []
```

### 시간/공간 복잡도

| 구분 | 복잡도 |
|------|--------|
| 시간 | O(n) |
| 공간 | O(n) |

---

## 핵심 정리

1. 해시맵을 사용하면 탐색을 O(1)로 줄일 수 있다
2. `complement` 패턴은 Two Sum 계열 문제에서 자주 사용된다
3. 인덱스를 저장하는 것이 핵심
