## 날짜별 초안 (drafts)

`drafts/YYYYMMDD/카테고리/` 형태로 파일을 추가하면 해당 날짜에 자동으로 발행됩니다.

예시:
```
drafts/
  20250102/
    코딩테스트/
      문제풀이.md
    자바/
      학습정리.md
```

## 자동화

- **GitHub Pages**: `main` 브랜치에 푸시 시 자동 배포
- **사이드바**: 폴더 구조 변경 시 `_sidebar.md` 자동 업데이트
- **날짜별 발행**: 매일 자정(KST) `drafts/YYYYMMDD/` 폴더 자동 발행
- **로컬 백데이트 커밋**: `bash scripts/auto-commit.sh` 실행
